# Linthra v0.2.12

Linthra 0.2.12 brings library improvements, Android HTTPS compatibility fixes, and additional stability work.

## Improvements

- Added initial album sorting support and server-provided music dates.
- Android HTTPS connections can now trust user-installed certificate authorities while retaining normal TLS certificate validation.
- GitHub Sponsors verification is now available in Google Play builds. Pro features remain locked until entitlement support is complete.

## Fixes

- Fixed playlist descriptions that could not be cleared.
- Avoided redundant artwork cache cleanup operations.
- Improved artwork cache test reliability by waiting for background operations before removing temporary files.

## Notes

- Restart Linthra after installing or removing a user CA certificate on Android.
- CUE sheet support is not included in this release.
