# Linthra v0.2.13

Linthra 0.2.13 adds CUE sheet support for local music, a cleaner Settings layout, and the first localized navigation labels. This release also includes internal stability and security improvements.

## Improvements

- Added support for importing and playing local tracks described by CUE sheets.
- Reorganized Settings into clearer groups and moved Support under About.
- Added the first localized navigation labels in English, French, and Portuguese. Most screens are not translated yet.

## Stability and tooling

- Added bounded byte-range planning helpers in the Rust core. These are internal groundwork and are not yet wired into Flutter playback.
- Added CodeQL analysis and tightened the CI fixer so it only handles trusted runs.
- Improved Linux audio smoke-test tooling.

## Notes

- Validate local CUE playback, background playback, and self-hosted sources before publishing.
- No online album-art provider or official artwork API integration is included.
