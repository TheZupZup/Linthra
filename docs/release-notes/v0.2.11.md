# Linthra v0.2.11

Linthra 0.2.11 is an urgent stability hotfix. It fixes a major bug in 0.2.10 on Android: music stopped when the screen turned off. If you are on 0.2.10, please update.

## Fixed: playback stopped with the screen off (0.2.10)

On Android 13 and later, Linthra 0.2.10 stopped playing a few seconds after the screen turned off or the phone locked, and the media notification and lock screen controls never appeared. It happened with every source: downloaded tracks, local files, and streams from Jellyfin, Navidrome and other servers.

The 0.2.10 release builds were missing the icons Linthra's media controls use. Without them, Android 13 and later could not set up the playback notification, so the background playback service never started, and Android silenced or stopped Linthra once the screen went off. Debug builds weren't affected, which is how it slipped through.

- Music keeps playing with the screen off or the phone locked.
- The media notification and lock screen controls are back.
- On Android 12 and older, where playback kept going, the notification buttons have their icons again.

Every Android release build is now checked for these icons before it can be published, so this can't ship again unnoticed.

Nothing else changes from 0.2.10. Linux is unaffected.

## Upgrade notes

No manual migration is needed. Update over 0.2.10 as usual.
